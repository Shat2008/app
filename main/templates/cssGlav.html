Основна інформація про CSS

Що таке CSS?

CSS (Cascading Style Sheets) — це каскадні таблиці стилів, які визначають зовнішній вигляд HTML-елементів. За допомогою CSS можна змінювати кольори, розміри, відступи, позиціювання та багато інших візуальних характеристик.

Коротка історія CSS

  • CSS1 (1996) — базові стилі: кольори, шрифти, відступи.
  • CSS2 (1998) — додано позиціювання, типи носіїв.
  • CSS3 (2011) — поділ на модулі, з’явились анімації, градієнти, тіні та багато іншого.

Основні можливості CSS

  • Кольори та шрифти: повний контроль над зовнішнім виглядом тексту.
  • Розміщення: можливість керувати позицією елементів (flexbox, grid).
  • Адаптивність: створення зручних інтерфейсів для будь-яких пристроїв.
  • Анімації: оживлення веб-сторінки без JavaScript.

Як підключити CSS?

Існує три способи підключення стилів:

  1. Вбудований стиль: усередині тегу <style> у HTML-документі.
  2. Зовнішній файл: через тег <link>, наприклад: 
    <link rel="stylesheet" href="styles.css">
  3. Inline-стиль: безпосередньо в тегу елемента, наприклад: 
    <p style="color:red;">Текст</p>

Як працює CSS?

Браузер читає CSS-правила зверху вниз, застосовуючи стилі до відповідних елементів HTML. Якщо декілька правил суперечать одне одному, застосовується те, що має більшу специфічність або знаходиться нижче у коді.

Переваги CSS

  • ✔ Відокремлює структуру (HTML) від дизайну (CSS).
  • ✔ Спрощує оновлення дизайну всього сайту.
  • ✔ Підвищує швидкість завантаження сторінок.
  • ✔ Підтримується всіма сучасними браузерами.

Недоліки CSS

  • ❌ Може по-різному відображатись у старих браузерах.
  • ❌ Для складних макетів потрібне розуміння моделей flex та grid.

Майбутнє CSS

CSS постійно розвивається — з’являються нові можливості, як-от змінні, контейнерні запити, покращені анімації. Це робить веб-розробку ще гнучкішою та красивішою.
