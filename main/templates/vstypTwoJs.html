Як підключити JavaScript до HTML

Щоб JavaScript почав працювати на веб-сторінці, його потрібно правильно підключити. Це можна зробити кількома способами — вибір залежить від того, де ти хочеш розмістити свій код.

1️⃣ Вбудований код у HTML

Можна написати код прямо всередині сторінки між тегами <script> і </script>:

<script>
alert("Привіт! Це повідомлення з JavaScript.");
</script>

Такий варіант зручно використовувати для коротких прикладів або тестів.

2️⃣ Зовнішній файл .js

Найкраща практика — створити окремий файл з розширенням .js (наприклад, script.js) і підключити його у кінці тіла сторінки:

<script src="script.js"></script>

Так код не змішується з HTML і легше підтримується. У Django шлях до файлу буде такий:

<script src="{% static 'js/script.js' %}"></script>

3️⃣ JavaScript у атрибутах HTML

Код можна написати безпосередньо у тегу, наприклад у кнопці:

<button onclick="alert('Ви натиснули кнопку!')">Натисни мене</button>

Однак цей спосіб використовують рідше, бо він змішує структуру (HTML) і логіку (JS).

📘 Приклад: зміна кольору тексту

<h2 id="text">Цей текст змінить колір</h2>
<button onclick="changeColor()">Змінити колір</button>

<script>
function changeColor() {
    document.getElementById("text").style.color = "blue";
}
</script>

При натисканні кнопки JavaScript знаходить елемент за його id і змінює його колір.

💡 Висновок:

  • ✔ JavaScript підключається через тег <script>.
  • ✔ Найкраще розміщувати код наприкінці тіла <body>.
  • ✔ Для великих проєктів — використовуй окремі .js файли.
