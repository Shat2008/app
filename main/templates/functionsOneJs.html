Функції та передача параметрів

Функції дозволяють об’єднувати код у блоки, які можна викликати багато разів. Вони роблять код чистішим і зручнішим для повторного використання.

🔹 Як створити функцію

function sayHello() {
    console.log("Привіт, світ!");
}

Щоб виконати функцію, потрібно її викликати:

sayHello();

🔹 Передача параметрів

Функції можуть приймати дані для обробки:

function greet(name) {
    console.log("Привіт, " + name + "!");
}
greet("Гліб"); // Привіт, Гліб!

🔹 Повернення значення

Функція може повертати результат для використання в іншому коді:

function sum(a, b) {
    return a + b;
}
let result = sum(5, 3);
console.log(result); // 8
