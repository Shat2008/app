Основні способи підключення CSS до HTML

Вступ

Після того як ми розібралися, що таке CSS, важливо навчитися правильно підключати стилі до HTML-документів. Існує кілька способів це зробити, і кожен із них має свої переваги та недоліки.

1. Зовнішній CSS-файл

Найпоширеніший і найзручніший спосіб — підключення окремого файлу стилів. Це дозволяє відокремити дизайн від структури сторінки та використовувати один CSS для багатьох HTML-документів.

Для цього у секції <head> додається тег <link>:


<link rel="stylesheet" href="style.css">

Файл style.css містить усі стилі, наприклад:


body {
    background-color: #f0f8ff;
    font-family: Arial, sans-serif;
}

h1 {
    color: darkblue;
    text-align: center;
}

Переваги:

  • ✅ Один файл можна використовувати для багатьох сторінок.
  • ✅ Зручно редагувати — усі стилі в одному місці.
  • ✅ Прискорює завантаження завдяки кешуванню.

Недолік: Потребує окремого файлу, тому стилі не видно без його відкриття.

2. Вбудовані стилі (всередині HTML)

Інший варіант — написати стилі прямо у секції <style> в межах HTML-документу.


<head>
    <style>
        p {
            color: green;
            font-size: 18px;
        }
    </style>
</head>

Переваги:

  • ✅ Не потрібно створювати додаткові файли.
  • ✅ Зручно для тестування або невеликих проєктів.

Недоліки:

  • ❌ Якщо сторінок багато — стилі доведеться копіювати вручну.
  • ❌ Важко підтримувати великий код.

3. Вбудовані (inline) стилі

Третій спосіб — додати стилі безпосередньо у тег HTML за допомогою атрибута style.


<p style="color:red; text-align:center;">Це приклад inline-стилю</p>

Переваги:

  • ✅ Швидко для тесту або одиничних випадків.

Недоліки:

  • ❌ Стиль не можна повторно використати.
  • ❌ Погано впливає на структуру коду.
  • ❌ Ускладнює редагування дизайну.

Висновок

Найкращим способом у більшості випадків є зовнішній CSS-файл, адже він забезпечує чисту структуру коду, швидке редагування та єдиний стиль для всього сайту. Інші методи зручно використовувати лише для тестів або дрібних прикладів.
