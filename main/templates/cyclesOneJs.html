Цикли в JavaScript

Цикли дозволяють повторювати виконання коду багато разів. Це зручно, коли потрібно працювати з масивами, рахувати значення або повторювати дії за певними умовами.

🔹 Цикл for

Використовується, коли відома кількість повторів:

for (let i = 1; i <= 5; i++) {
    console.log("Номер:", i);
}

🔹 Цикл while

Виконується, доки умова true:

let i = 1;
while (i <= 5) {
    console.log("Число:", i);
    i++;
}

🔹 Цикл do...while

Спочатку виконує код, потім перевіряє умову — виконується хоча б один раз:

let num = 1;
do {
    console.log("num =", num);
    num++;
} while (num <= 5);

🔹 Цикл for...of

Перебирає елементи масиву:

let fruits = ["яблуко", "банан", "вишня"];
for (let fruit of fruits) {
    console.log(fruit);
}

🔹 Цикл for...in

Перебирає властивості об'єкта:

let person = {name: "Гліб", age: 16};
for (let key in person) {
    console.log(key + ":", person[key]);
}
