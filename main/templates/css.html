HTML (структура сторінки)

У HTML-коді використовується механізм перевертання елементів за допомогою якорів (id="target"). Основні елементи:

  • {% load static %} – підключає статичні файли (наприклад, CSS) у Django.
  • <div class="flipper" id="target"> – контейнер, що містить передню (.front) і задню (.back) сторони картки.
  • Кнопка "Про мене" (<a href="#target" class="home button">) активує перевертання.
  • Соцмережі (.share-block) містять іконки посилань.
  • Заголовок "ДИЗАЙН & КОД" відображається на передній стороні.
  • На зворотній стороні є кнопка close, яка повертає картку у вихідне положення (<a href="#close" class="close button">).
  • У блоці .inner міститься текстовий опис.

CSS (стилі та анімація)

Цей CSS-код визначає зовнішній вигляд і поведінку сторінки:

  • background: url(photo-morning-rose.jpg); задає фон для всієї сторінки.
  • Анімація перевертання реалізується через transform: rotateX(180deg);.
  • .container створює 3D-ефект за допомогою perspective: 1200px;.
  • .flipper:target змінює стан елемента .flipper, що викликає перевертання.
  • .button оформлює кнопки ("Про мене" та "Закрити").
  • Медіа-запит (@media (max-width: 768px)) адаптує розмітку для мобільних пристроїв, зменшуючи розмір тексту.

Як це працює?

  1. При завантаженні сторінки видно лише передню частину картки.
  2. Натискання на "Про мене" переводить браузер за якорем #target, змінюючи стиль transform: rotateX(180deg);, що перевертає картку.
  3. Натискання на кнопку "Закрити" повертає картку назад (#close).

CSS (стилі та анімація)

Цей CSS-код визначає зовнішній вигляд сторінки, стилі блоків і анімації 3D-трансформацій.

        
            body {

                text-align: center;
                background: #F4F1F8;
            }
            h1 {

            }
            .container {

                display: inline-block;

            }

                position: absolute;
                bottom: 0;
                background: rgba(65, 245, 254, .5);
                border-radius: 5px;
                animation: notransform 5s infinite;
            }
            .translate3d {
                transform: translate3d(20px,20px,20px);
            }
            .scale3d {
                transform: scale3d(0,0,1);
                animation-delay: .5s;
            }
            .rotate3d {
                transform: rotate3d(1, .5, 1, -30deg);
                animation-delay: 1s;
            }
            .rotateX {
                transform: rotateX(180deg);
                animation-delay: 1.5s;
            }
            .rotateY {
                transform: rotateY(180deg);
                animation-delay: 2s;
            }
            .rotateZ {
                transform: rotateZ(180deg);
                animation-delay: 2.5s;
            }
            @keyframes notransform {
                50% {transform: none;}
            }

Як це працює?

Кожен блок .container містить елемент .transform, до якого застосовані 3D-трансформації.

  • Трансформація translate3d зміщує елемент у тривимірному просторі.
  • scale3d змінює розмір елемента у трьох напрямках.
  • rotate3d, rotateX, rotateY, rotateZ обертають елементи навколо відповідних осей.
  • Властивість perspective у .container додає ефект глибини.
  • Анімація @keyframes notransform періодично повертає елементи у початковий стан.

CSS (стилі та анімація)

Цей CSS-код задає стилі для блоків, визначає 3D-обертання та додає ефекти анімації.

        
            @keyframes anim {
                from {
                    transform: rotateY(-120deg);
                }
                to {
                    transform: rotateY(240deg);
                }
            }
            
            #outer {
                width: 1000px;
            }
            
            #wrapper {
                float: right;
                width: 500px;
                height: 100px;
                margin-top: 100px;
                position: relative;
                animation: anim 20s infinite linear;
                transform-origin: left;
                transform-style: preserve-3d;
            }
            
            #wrapper>div {
                width: 500px;
                height: 300px;
                backface-visibility: visible;
                position: absolute;
                transform-origin: left;
            }
            
            .show {
                width: 300px;
                height: 100%;
                color: #ffffff;
                text-align: center;
                box-sizing: border-box;
                padding: 30px;
                font-size: 33px;
                float: left;
                transform: rotateY(180deg);
            }
            
            #t6 { transform: rotateY(300deg); }
            #t5 { transform: rotateY(240deg); }
            #t4 { transform: rotateY(180deg); }
            #t3 { transform: rotateY(120deg); }
            #t2 { transform: rotateY(60deg); }
            #t1 { transform: rotateY(0deg); }
            
            #t6 div.show { background-color: #8e3a09; }
            #t5 div.show { background-color: #6d2176; }
            #t4 div.show { background-color: #b58224; }
            #t3 div.show { background-color: #83890e; }
            #t2 div.show { background-color: #ff0000; }
            #t1 div.show { background-color: #0000ff; }
            
            #wrapper .small {
                font-size: 19px;
            }

Як це працює?

  • Блок #wrapper містить кілька внутрішніх блоків #t1 - #t6, які представляють різні текстові елементи.
  • Анімація @keyframes anim здійснює обертання #wrapper навколо осі Y.
  • Кожен текстовий блок має свою позицію завдяки transform: rotateY().
  • Для створення 3D-ефекту використовується transform-style: preserve-3d; та perspective.
  • Кольори кожного блока задаються індивідуально через класи #t1 div.show - #t6 div.show.
