Умови if, else, switch у JavaScript

Умови дозволяють програмі приймати рішення: виконувати певні дії лише тоді, коли виконується якась умова.

🔹 Оператор if

Оператор if перевіряє умову і виконує код, якщо вона true.

let age = 18;

if (age >= 18) {
    console.log("Ти повнолітній!");
}

🔹 if...else

Якщо умова не виконується, можна вказати іншу дію через else:

let time = 20;

if (time < 18) {
    console.log("Добрий день!");
} else {
    console.log("Добрий вечір!");
}

🔹 if...else if...else

Можна додавати кілька умов підряд:

let score = 75;

if (score >= 90) {
    console.log("Відмінно!");
} else if (score >= 70) {
    console.log("Добре!");
} else {
    console.log("Спробуй ще раз.");
}

🔹 switch

Оператор switch використовується, коли є багато варіантів вибору.

let day = 3;
let dayName;

switch (day) {
    case 1:
        dayName = "Понеділок";
        break;
    case 2:
        dayName = "Вівторок";
        break;
    case 3:
        dayName = "Середа";
        break;
    default:
        dayName = "Невідомий день";
}

console.log(dayName);
