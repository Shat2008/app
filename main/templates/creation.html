HTML (HyperText Markup Language) – це основа будь-якого веб-сайту

Вона використовується для створення та структурування веб-сторінок, додаючи текст, зображення, посилання, таблиці, форми та інші елементи. HTML дозволяє веб-браузерам інтерпретувати вміст сторінки та правильно його відображати. Щоб створити базовий HTML-файл, потрібно всього лише текстовий редактор (наприклад, Notepad, Visual Studio Code, Sublime Text або навіть стандартний "Блокнот" у Windows). Сам файл повинен мати розширення .html, щоб браузери могли правильно його розпізнати та відобразити.

Як створити HTML-файл

Перший крок – це відкриття текстового редактора. Якщо ти використовуєш Notepad, просто відкрий його, введи код і збережи файл із розширенням .html. Наприклад, якщо ти хочеш створити веб-сторінку під назвою "index", тобі потрібно зберегти файл як index.html. Важливо переконатися, що в налаштуваннях збереження вибраний "Усі файли" (All Files), щоб уникнути випадкового збереження як текстового документа.

Запуск HTML-файлу в браузері

Щоб переглянути HTML-файл у браузері, достатньо двічі клікнути на нього – система автоматично відкриє його у стандартному браузері. Якщо ж потрібно перевірити, як сторінка виглядає в іншому браузері (наприклад, Google Chrome, Mozilla Firefox, Microsoft Edge або Opera), можна просто відкрити браузер, натиснути Ctrl + O (або Cmd + O на Mac), а потім вибрати потрібний HTML-файл.

Вміст HTML-файлу

Якщо відкрити порожній HTML-файл у браузері, то на екрані не з’явиться нічого, окрім білої сторінки. Але якщо додати хоча б простий текст або заголовок, його вже можна буде побачити. Наприклад:

        <h1>Привіт, світ!</h1>

Для кращого вигляду можна також використовувати CSS (каскадні таблиці стилів), які дозволяють змінювати шрифти, кольори, розміщення елементів та багато іншого.

Використання редакторів коду

Для написання HTML рекомендується використовувати редактори коду, які мають підсвічування синтаксису та додаткові функції для веб-розробки. Найпопулярніші редактори:

  • Visual Studio Code – безкоштовний, має велику кількість плагінів та підтримку розширень.
  • Sublime Text – швидкий і легкий редактор із мінімалістичним інтерфейсом.
  • Atom – редактор від GitHub із широкими можливостями розширення, хоча його підтримка припинена.
  • Notepad++ – легкий текстовий редактор для Windows, що підтримує багато мов програмування.
