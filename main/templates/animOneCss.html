CSS transitions — плавні зміни властивостей

1. Що таке CSS transitions

CSS transitions дозволяють плавно змінювати значення властивостей елемента при певних подіях (наприклад, hover, focus).

2. Основний синтаксис


transition: property duration timing-function delay;
  • property — властивість, яку будемо анімувати (наприклад, color, background-color, width)
  • duration — тривалість переходу (наприклад, 0.5s, 2s)
  • timing-function — тип прискорення (ease, linear, ease-in, ease-out)
  • delay — затримка перед початком (наприклад, 0s, 1s)

3. Приклад

Плавна зміна фону і кольору тексту при наведенні:


.button {
    background-color: #3498db;
    color: white;
    padding: 10px 20px;
    border: none;
    transition: background-color 0.5s ease, color 0.5s ease;
}

.button:hover {
    background-color: #2ecc71;
    color: black;
}

4. Поради

  • ✅ Використовуйте transitions для невеликих ефектів.
  • ✅ Не анімуйте властивості, що впливають на layout (width, height, margin), якщо можна уникнути.
  • ✅ Комбінуйте з hover або focus для інтерактивних ефектів.
