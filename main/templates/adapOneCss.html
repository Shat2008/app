Медіа-запити для адаптивного дизайну

1. Що таке медіа-запити

Медіа-запити дозволяють змінювати стиль сайту в залежності від розміру екрана, орієнтації пристрою або інших параметрів. Це основний інструмент адаптивного дизайну.

2. Основний синтаксис


@media (max-width: 768px) {
    body {
        background-color: lightblue;
    }
    .sidebar {
        display: none;
    }
}
  • max-width — застосування стилів при ширині екрана менше або рівній значенню.
  • min-width — застосування стилів при ширині екрана більше або рівній значенню.
  • Можна комбінувати кілька умов через and, or.

3. Приклади

Змінюємо макет для планшетів і мобільних пристроїв:


/* Планшети */
@media (max-width: 1024px) {
    .content {
        width: 80%;
    }
}

/* Мобільні */
@media (max-width: 480px) {
    .content {
        width: 100%;
    }
    nav, .sidebar {
        display: none;
    }
}

4. Поради

  • ✅ Використовуйте гнучкі одиниці (%, em, rem) замість px.
  • ✅ Плануйте макет “mobile-first”, спочатку стилі для мобільних, а потім для більших екранів.
  • ✅ Тестуйте сайт на різних пристроях та розмірах екранів.
