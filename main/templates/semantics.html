Семантичні елементи в HTML

1. <header> (Шапка)

Цей елемент зазвичай використовується для розміщення вступної інформації про сторінку або розділ. У шапці можуть бути розміщені логотип, заголовок сайту, навігаційне меню та інші елементи, які зазвичай знаходяться в верхній частині сторінки.

Приклад:

    
    <header>
      <h1>Мій сайт</h1>
      <nav>
        <ul>
          <li><a href="#home">Головна</a></li>
          <li><a href="#about">Про нас</a></li>
          <li><a href="#services">Послуги</a></li>
          <li><a href="#contact">Контакти</a></li>
        </ul>
      </nav>
    </header>
Продивитися результат

Пояснення:

У цьому прикладі в елементі <header> розміщені:

  • <h1> — назва сайту.
  • <nav> — навігаційне меню, що містить посилання на основні розділи сайту.

Шапка допомагає структуризувати сторінки та полегшує навігацію.

2. <main> (Основний контент)

Елемент <main> використовується для позначення основного контенту сторінки. У ньому міститься унікальна інформація, яка є основною для цієї сторінки. Це основний розділ, який не повторюється на сторінці (тобто один елемент <main> на сторінці).

Приклад:

    
    <main>
      <section>
        <h2>Наші послуги</h2>
        <p>Ми пропонуємо високоякісні послуги з розробки веб-сайтів.</p>
      </section>
  
      <section>
        <h2>Про компанію</h2>
        <p>Наша компанія займається розробкою та дизайном з 2005 року.</p>
      </section>
    </main>
Продивитися результат

Пояснення:

У середині <main> знаходяться два розділи (використовуємо <section> для поділу контенту):

  • Перший розділ містить інформацію про послуги компанії.
  • Другий розділ містить опис компанії.

Все вміст у <main> важливе для розуміння того, про що йде мова на сторінці.

3. <footer> (Підвал)

Цей елемент позначає підвал сторінки або розділу. Зазвичай у підвалі міститься інформація про авторські права, контактні дані, посилання на політику конфіденційності, мапу сайту та інші допоміжні елементи.

Приклад:

    
    <footer>
      <p>© 2025 Мій сайт. Усі права захищено.</p>
      <ul>
        <li><a href="#privacy">Політика конфіденційності</a></li>
        <li><a href="#terms">Умови використання</a></li>
      </ul>
      <address>
        <p>Контакти: <a href="mailto:info@example.com">info@example.com</a></p>
      </address>
    </footer>
Продивитися результат

Пояснення:

В елементі <footer> розміщено:

  • Параграф з інформацією про авторські права.
  • Посилання на сторінки з політикою конфіденційності та умовами використання.
  • Контактний адресу з посиланням на email.

Цей елемент допомагає користувачам знайти важливу інформацію в нижній частині сторінки.

Для чого потрібні семантичні елементи?

Семантичні елементи (такі як <header>, <main>, та <footer>) мають важливу роль у покращенні доступності, пошукової оптимізації (SEO) та структуризації документа:

  • SEO: Допомагають пошуковим системам (Google, Bing тощо) правильно інтерпретувати структуру та вміст сторінки.
  • Доступність: Семантичні елементи допомагають користувачам, які використовують екранні читалки та інші допоміжні технології, швидше орієнтуватися на сторінці.
  • Структура: Вони надають структуру веб-сторінці, покращуючи сприйняття та зручність навігації як для користувачів, так і для розробників.

Ці елементи роблять HTML більш читабельним і логічним, що сприяє покращенню користувацького досвіду та взаємодії з сайтом.

4. <section> (Розділ)

Елемент <section> використовується для групування пов'язаного контенту у тематичні розділи. Кожна секція зазвичай містить заголовок та відповідний вміст.

    
    <section>
      <h2>Заголовок розділу</h2>
      <p>Вміст розділу...</p>
    </section>
Продивитися результат

5. <article> (Стаття)

Елемент <article> позначає незалежний, самодостатній вміст, такий як дописи в блозі, новини або коментарі. Це важливо для SEO та доступності.

    
    <article>
      <h2>Назва статті</h2>
      <p>Вміст статті...</p>
    </article>

6. <nav> (Навігація)

Елемент <nav> містить навігаційні посилання на основні розділи сайту.

    
    <nav>
      <ul>
        <li><a href="/">Головна</a></li>
        <li><a href="/about">Про нас</a></li>
        <li><a href="/contact">Контакти</a></li>
      </ul>
    </nav>

7. <aside> (Бічна панель)

Елемент <aside> використовується для контенту, який не входить в основний потік сторінки (наприклад, бічна панель, реклама).

    
    <aside>
      <h3>Гарячі новини</h3>
      <p>Інформація на бічній панелі...</p>
    </aside>
