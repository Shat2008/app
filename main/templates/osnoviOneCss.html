Селектори, властивості та значення в CSS

Що таке селектори?

Селектори — це частина CSS, яка визначає, до яких елементів HTML застосовуватимуться стилі. Вони «вибирають» елементи для оформлення.

Найпростіший приклад:


p {
    color: blue;
}

Тут селектором є p — усі абзаци на сторінці стануть синіми.

Основні типи селекторів

  • За тегом — впливає на всі елементи певного типу: h1 { color: red; }
  • За класом — використовується з крапкою: .text { font-size: 18px; }
  • За ідентифікатором — починається з решітки: #main { background: yellow; }
  • Універсальний селектор — зірочка * вибирає всі елементи: * { margin: 0; }
  • Комбіновані селектори — кілька умов одночасно: div p { color: green; }

Що таке властивості?

Властивість — це характеристика елемента, яку ми змінюємо. Наприклад, колір, розмір шрифту, фон тощо.

У CSS властивості пишуться у вигляді пар «властивість: значення»:


h1 {
    color: red;
    font-size: 30px;
    text-align: center;
}

У цьому прикладі елемент <h1> буде червоним, розміром 30px і вирівняний по центру.

Значення властивостей

Значення — це конкретне налаштування властивості. Вони можуть бути різних типів: числа, кольори, ключові слова, відсотки, одиниці вимірювання тощо.

Приклади:


color: #ff0000;        /* колір у HEX */
font-size: 20px;       /* розмір у пікселях */
margin: 10%;           /* відступ у відсотках */
font-weight: bold;     /* товщина шрифту */
background-color: blue; /* колір фону */

Приклад використання селекторів на сторінці


<!DOCTYPE html>
<html>
<head>
    <style>
        body { background-color: #f0f0f0; }
        h1 { color: darkred; }
        .info { color: green; }
        #footer { text-align: center; font-size: 14px; }
    </style>
</head>
<body>
    <h1>Приклад селекторів</h1>
    <p class="info">Цей текст зелений, бо має клас "info".</p>
    <div id="footer">Низ сторінки</div>
</body>
</html>

Висновок

Селектори, властивості та значення — це основа CSS. Селектори визначають, що змінювати, властивості — яку характеристику, а значення — на що саме її замінити.

Розуміння цих трьох елементів дозволяє створювати красиві та структуровані вебсторінки.
