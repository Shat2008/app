LocalStorage, JSON та Fetch API

У цьому розділі ми розглянемо способи зберігання даних у браузері та роботу з даними з серверу.

🔹 LocalStorage

LocalStorage дозволяє зберігати дані у браузері користувача навіть після перезавантаження сторінки.

localStorage.setItem('name', 'Оля');
const name = localStorage.getItem('name');
console.log(name); // "Оля"

🔹 JSON

JSON використовується для обміну даними між сервером і клієнтом у вигляді тексту.

const user = {name: "Оля", age: 20};
const json = JSON.stringify(user); // перетворюємо об'єкт у JSON
const obj = JSON.parse(json); // перетворюємо JSON назад у об'єкт

🔹 Fetch API

Fetch API дозволяє робити запити до сервера та отримувати дані асинхронно.

fetch('https://jsonplaceholder.typicode.com/users')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.log('Помилка:', error));

💡 Висновок:

  • ✔ LocalStorage зберігає дані в браузері користувача.
  • ✔ JSON дозволяє легко передавати дані між клієнтом і сервером.
  • ✔ Fetch API допомагає отримувати та обробляти дані асинхронно.
