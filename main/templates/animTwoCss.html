CSS animations — створення рухомих ефектів

1. Що таке CSS animations

CSS анімації дозволяють створювати складні рухомі ефекти без використання JavaScript. На відміну від transitions, анімації можуть повторюватися та складатися з ключових кадрів.

2. Основний синтаксис


selector {
    animation-name: name;
    animation-duration: 2s;
    animation-timing-function: ease;
    animation-delay: 0s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
}
  • animation-name — ім’я анімації, визначеної через @keyframes.
  • animation-duration — тривалість анімації.
  • animation-timing-function — функція прискорення (ease, linear, ease-in-out).
  • animation-delay — затримка перед початком.
  • animation-iteration-count — кількість повторень (наприклад, infinite).
  • animation-direction — напрямок (normal, reverse, alternate).

3. Приклад анімації

Проста анімація зміни кольору та позиції блоку:


@keyframes example {
    0%   {background-color: red; left: 0px;}
    50%  {background-color: yellow; left: 100px;}
    100% {background-color: green; left: 0px;}
}

.box {
    width: 50px;
    height: 50px;
    position: relative;
    animation-name: example;
    animation-duration: 4s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
}

4. Поради

  • ✅ Використовуйте анімації для привертання уваги користувача.
  • ✅ Поєднуйте з transitions для складних ефектів.
  • ✅ Уникайте надмірного використання, щоб не перевантажити інтерфейс.
