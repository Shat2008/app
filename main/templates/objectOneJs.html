Об’єкти та робота з ними

Об’єкти дозволяють зберігати дані у вигляді пар ключ-значення і працювати з ними структуровано.

🔹 Створення об’єкта

let person = {
    name: "Оля",
    age: 25,
    isStudent: true
};

🔹 Доступ до властивостей

Можна отримати або змінити значення властивості:

console.log(person.name); 
person.age = 17;
console.log(person.age); // 26

🔹 Додавання та видалення властивостей

person.city = "Дніпро"; // додаємо
delete person.isStudent; // видаляємо

🔹 Методи об’єкта

Функції можна зберігати як методи об’єкта:

let person = {
    name: "Оля",
    greet: function() {
        console.log("Привіт, я " + this.name);
    }
};

person.greet(); // Привіт, я Гліб

  • ✔ Можна додавати, видаляти та використовувати методи для об’єктів.
