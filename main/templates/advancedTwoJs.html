Асинхронність і проміси

Асинхронність дозволяє JavaScript виконувати довгі операції (наприклад, запит до сервера) без блокування інтерфейсу.

🔹 Проміси (Promise)

Promise — це об’єкт, який представляє результат асинхронної операції.

const myPromise = new Promise((resolve, reject) => {
    const success = true;
    if(success) {
        resolve("Операція успішна!");
    } else {
        reject("Сталася помилка!");
    }
});

myPromise
    .then(result => console.log(result))
    .catch(error => console.log(error));

🔹 Async / Await

Сучасний синтаксис для роботи з промісами у більш зручній формі.

async function fetchData() {
    try {
        const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
        const data = await response.json();
        console.log(data);
    } catch(error) {
        console.log("Помилка:", error);
    }
}

fetchData();

💡 Висновок:

  • ✔ Асинхронність дозволяє не блокувати сторінку при очікуванні результату.
  • ✔ Проміси спрощують обробку асинхронних дій.
  • ✔ Async/Await робить код чистішим і легким для читання.
