Кольори: HEX, RGB, RGBA, HSL

У CSS кольори можна задавати кількома способами: HEX, RGB, RGBA та HSL.

1. HEX (шістнадцятковий запис)

Колір задається у форматі #RRGGBB, де RR, GG, BB — це значення червоного, зеленого та синього від 00 до FF.

  • #FF0000 — червоний
  • #00FF00 — зелений
  • #0000FF — синій

2. RGB (Red, Green, Blue)

Колір задається через червоний, зелений та синій компоненти у десятковому вигляді від 0 до 255:

  • rgb(255, 0, 0) — червоний
  • rgb(0, 255, 0) — зелений
  • rgb(0, 0, 255) — синій

3. RGBA (Red, Green, Blue, Alpha)

Як RGB, але додається параметр alpha для прозорості від 0 (повністю прозорий) до 1 (повністю непрозорий):

  • rgba(255, 0, 0, 0.5) — напівпрозорий червоний

4. HSL (Hue, Saturation, Lightness)

Колір задається через відтінок (Hue, 0–360°), насиченість (Saturation, %) та світлість (Lightness, %):

  • hsl(0, 100%, 50%) — чистий червоний
  • hsl(120, 100%, 50%) — чистий зелений
  • hsl(240, 100%, 50%) — чистий синій

Кожен із цих способів можна використовувати в CSS-властивостях, таких як color, background-color, border-color тощо.
