Зображення, прозорість та градієнти

1. Фонові зображення

Можна задати зображення як фон елементу.


background-image: url('image.jpg');
background-size: cover; /* Покриває весь блок */
background-repeat: no-repeat; /* Не повторювати */
background-position: center; /* Центрування */

2. Прозорість (opacity)

Прозорість елементу задається властивістю opacity.


div {
    opacity: 0.7; /* 0 - повністю прозорий, 1 - непрозорий */
}

Можна використовувати rgba для кольорів з прозорістю:


background-color: rgba(255, 0, 0, 0.5); /* напівпрозорий червоний */

3. Градієнти

Градієнти дозволяють плавно змінювати кольори.


background: linear-gradient(to right, red, yellow);
background: radial-gradient(circle, blue, lightblue);
