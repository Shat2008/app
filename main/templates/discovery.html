Відкриття HTML-файлу у браузері

1. Відкриття HTML-файлу подвійним кліком

Це найпростіший і найшвидший спосіб.

  1. Перейдіть до папки, де збережено HTML-файл.
  2. Двічі клацніть по файлу (index.html або іншому .html-файлу).
  3. Файл відкриється у браузері за замовчуванням (Chrome, Firefox, Edge, Safari тощо).

Примітка: Якщо файл відкривається в текстовому редакторі, можливо, потрібно змінити програму за замовчуванням для відкриття .html-файлів.

2. Відкриття файлу через контекстне меню

  1. Клацніть правою кнопкою миші на HTML-файлі.
  2. Оберіть "Відкрити за допомогою".
  3. Виберіть браузер, який ви хочете використовувати (Google Chrome, Mozilla Firefox, Microsoft Edge тощо).

3. Перетягування файлу у вікно браузера

  1. Відкрийте веб-браузер.
  2. Відкрийте папку з вашим HTML-файлом.
  3. Перетягніть файл у вікно браузера.
  4. Браузер автоматично завантажить і відобразить сторінку.

4. Відкриття HTML-файлу через браузер (гарячі клавіші)

  1. Відкрийте браузер.
  2. Натисніть Ctrl + O (Cmd + O на macOS).
  3. З'явиться вікно вибору файлу.
  4. Виберіть ваш HTML-файл та натисніть "Відкрити".

5. Відкриття HTML-файлу у браузері через командний рядок (термінал)

На Windows (CMD або PowerShell)

cd C:\Users\ВашКористувач\Documents
start chrome index.html
start msedge index.html

На macOS (Термінал)

cd ~/Documents
open -a Safari index.html
open -a "Google Chrome" index.html

На Linux (Термінал)

cd ~/Documents
firefox index.html
google-chrome index.html

6. Відкриття HTML-файлу у браузері з текстового редактора

Visual Studio Code

  1. Встановіть розширення Live Server.
  2. Відкрийте HTML-файл у VS Code.
  3. Натисніть "Go Live" у нижній панелі.

Sublime Text

  1. Відкрийте HTML-файл у Sublime Text.
  2. Натисніть Ctrl + Shift + B (або Cmd + Shift + B на macOS).

7. Перегляд HTML-коду у браузері

  • Правий клік → "Переглянути вихідний код сторінки"
  • Натисніть Ctrl + U (Cmd + U на Mac)

8. Використання локального веб-сервера для перегляду HTML-файлів

Python (для швидкого запуску)

python -m http.server 8000

Потім відкрийте у браузері http://localhost:8000/.

Node.js (з використанням пакета http-server)

npx http-server

Потім відкрийте http://localhost:8080/.

9. Що робити, якщо HTML-файл не відкривається у браузері?

  • ✅ Файл має правильне розширення .html.
  • ✅ Шлях до файлу правильний.
  • ✅ Немає помилок у коді (відкрийте Інструменти розробника → F12 → Console).
  • ✅ Спробуйте інший браузер.
  • ✅ Переконайтесь, що локальний сервер запущено (якщо використовуєте AJAX або JavaScript).
