HTML — це основа веб-розробки, мова розмітки гіпертексту, яка використовується для створення структури веб-сторінок. Основні теги HTML відповідають за визначення структури та вмісту документа. Найважливішими тегами є <html>, <head> і <body>. Розглянемо їх докладніше.

Тег <html>

Тег <html> є кореневим елементом будь-якого документа HTML. Він охоплює весь код сторінки та повідомляє браузеру, що це HTML-документ. Всі інші елементи, такі як <head> і <body>, знаходяться всередині тегу <html>. Цей тег завжди має бути на початку та в кінці документа.

Приклад:




    <!DOCTYPE html>
    <html>
        <head>
            <meta charset="UTF-8">
            <title Проста сторінка /title>
        </head>
        <body>
            <h1 Ласкаво просимо! /h1 >
        </body>
    </html>

Тег <head>

Тег <head> містить метаінформацію про сторінку. Це інформація, яка не відображається безпосередньо на веб-сторінці, але необхідна для роботи сайту та взаємодії з браузером. Усередині тегу <head> розміщуються різні мета-теги, посилання на стилі, скрипти та інші елементи, що впливають на відображення та функціональність сторінки.

Приклад вмісту тегу <head>:


<head>
    <meta charset="UTF-8"> <!-- Встановлює кодування документа -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Налаштування адаптивності -->
    <title>Заголовок сторінки</title> <!-- Заголовок сторінки -->
    <link rel="stylesheet" href="styles.css"> <!-- Посилання на зовнішній CSS-файл -->
    <script src="script.js"></script> <!-- Посилання на зовнішній JavaScript файл -->
</head>

Основні елементи всередині тегу <head>:

  • <meta charset="UTF-8"> — визначає кодування документа (важливо для коректного відображення символів).
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> — робить сторінку адаптивною на мобільних пристроях.
  • <title> — визначає назву сторінки, яка відображається на вкладці браузера.
  • <link> — використовується для підключення зовнішніх файлів, таких як CSS.
  • <script> — для підключення зовнішніх файлів JavaScript або для написання скриптів всередині сторінки.

Тег <body>

Тег <body> містить всі елементи, які відображаються на веб-сторінці. Це текст, зображення, таблиці, посилання, форми та інші елементи контенту, видимі для користувача. На відміну від тегу <head>, який відповідає за метаінформацію, <body> призначений для відображення інформації.

Приклад:


<!DOCTYPE html>
<html>
<body>
    <h1>Ласкаво просимо на мій сайт!/h1>
    <p>Це абзац тексту на сторінці./p>
</body>
</html>
</body>
Продивитися результат

Основні елементи всередині тегу <body>:

  • <h1> — заголовок першого рівня. HTML підтримує шість рівнів заголовків (від <h1> до <h6>), де <h1> є найважливішим, а <h6> — найменш важливим.
  • <p> — абзац тексту. Це базовий елемент для тексту на сторінці.

Структура документа HTML

Документ HTML має чітку ієрархію. Важливим моментом є те, що правильне використання тегів гарантує, що сторінка буде правильно інтерпретована браузером. Розглянемо типову структуру документа:


<!DOCTYPE html> <!-- Декларація типу документа, необхідна для HTML5 -->
<html lang="uk"> <!-- Вказівка на мову сторінки -->
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Приклад документа HTML</title>
        <link rel="stylesheet" href="styles.css">
        <script src="script.js"></script>
    </head>
    <body>
        <h1>Заголовок сторінки</h1>
        <p>Текст абзацу.</p>
        <a href="https://example.com">Посилання на інший сайт</a>
    </body>
</html>
Продивитися результат

Декларація <!DOCTYPE html>

Перед тегом <html> зазвичай ставиться декларація типу документа. Для HTML5 використовується <!DOCTYPE html>. Цей тег не є елементом HTML, але він необхідний для того, щоб браузер правильно інтерпретував сторінку як HTML5-документ. Він повідомляє браузеру, що сторінка використовує специфікацію HTML5, і дозволяє уникнути проблем з рендерингом сторінки.

Інші важливі теги HTML

Таблиці

Таблиці використовуються для відображення табульованих даних. Основні теги для таблиць:

  • <table> — контейнер для таблиці.
  • <tr> — рядок таблиці (table row).
  • <td> — комірка даних (table data).
  • <th> — комірка заголовка таблиці (table header).
  • <thead> — група рядків заголовка.
  • <tbody> — група рядків з основним вмістом.
  • <tfoot> — група рядків підсумків.

Приклад таблиці:


<table border="1">
  <thead>
    <tr>
      <th>Ім'я</th>
      <th>Вік</th>
      <th>Місто</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Іван</td>
      <td>25</td>
      <td>Київ</td>
    </tr>
    <tr>
      <td>Марія</td>
      <td>30</td>
      <td>Харків</td>
    </tr>
  </tbody>
</table>

Форми

Форми використовуються для зібрання інформації від користувачів. Основні теги для форм:

  • <form> — контейнер для форми.
  • <input> — поле введення (текст, пароль, чекбокс, радіокнопка тощо).
  • <textarea> — багаторядкове текстове поле.
  • <select> — випадаючий список.
  • <button> — кнопка.
  • <label> — позначка для форми.

Приклад форми:


<form action="/submit" method="POST">
  <label for="name">Ім'я:</label>
  <input type="text" id="name" name="name" required>
  
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  
  <label for="message">Повідомлення:</label>
  <textarea id="message" name="message" rows="4"></textarea>
  
  <button type="submit">Відправити</button>
</form>

Фрейми (iframe)

Фрейм (iframe) дозволяє вставити одну веб-сторінку всередину іншої. Це корисно для вставлення карт, відео або іншого контенту з інших сайтів.

Приклад фрейму:


<!-- Вставлення відео з YouTube -->
<iframe width="560" height="315" src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
    frameborder="0" allowfullscreen></iframe>

<!-- Вставлення Google Map -->
<iframe src="https://www.google.com/maps/embed?pb=..." width="600" height="450" 
    style="border:0;" allowfullscreen="" loading="lazy"></iframe>

Мультимедіа: Аудіо та Відео

Для вставлення аудіо та відео контенту використовуються теги <audio> та <video>:

Приклад відео:


<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.ogg" type="video/ogg">
  Ваш браузер не підтримує тег video.
</video>

Приклад аудіо:


<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Ваш браузер не підтримує тег audio.
</audio>

Списки

HTML підтримує три типи списків:

  • <ul> — невпорядкований список (з точками).
  • <ol> — впорядкований список (з номерами).
  • <dl> — список визначень.

Приклад списків:


<!-- Невпорядкований список -->
<ul>
  <li>Перший елемент</li>
  <li>Другий елемент</li>
  <li>Третій елемент</li>
</ul>

<!-- Впорядкований список -->
<ol>
  <li>Перший крок</li>
  <li>Другий крок</li>
  <li>Третій крок</li>
</ol>

Зображення

Для вставлення зображень використовується тег <img>:


<img src="image.jpg" alt="Опис зображення" width="300" height="200">

Посилання

Тег <a> використовується для створення посилань на інші сторінки або ресурси:


<!-- Посилання на іншу сторінку -->
<a href="https://example.com">Перейти на example.com</a>

<!-- Посилання на email -->
<a href="mailto:info@example.com">Відправити email</a>

<!-- Посилання на номер телефону -->
<a href="tel:+380123456789">+38 (012) 345-67-89</a>

Інші важливі теги

  • <div> — контейнер для групування елементів (блоковий елемент).
  • <span> — контейнер для групування елементів (вбудований елемент).
  • <strong> — сильний наголос (жирний текст).
  • <em> — наголос (курсивний текст).
  • <br> — розрив рядка.
  • <hr> — горизонтальна лінія.
  • <blockquote> — довга цитата.
  • <code> — вставка коду.
  • <pre> — попередньо відформатований текст.

Висновок

HTML має багато тегів, які дозволяють створювати складні та багатофункціональні веб-сторінки. Розуміння призначення кожного тегу дозволяє створювати семантично коректні і доступні веб-сайти. Постійно вивчайте нові можливості HTML та експериментуйте з їх використанням.

Багато тегів HTML можуть мати атрибути, які змінюють їх поведінку або вигляд. Наприклад, атрибут href в тегу <a> вказує посилання, атрибут src в тегу <img> вказує шлях до зображення, а атрибут class використовується для стилізації елементів через CSS.

Приклад з атрибутами:


<a href="https://www.example.com" target="_blank">Перейти на сайт</a> <!-- Посилання на зовнішній сайт -->
<img src="image.jpg" alt="Опис зображення" width="500" height="300"> <!-- Зображення з вказаними розмірами -->
<button class="btn-primary">Натисни мене!</button> <!-- Кнопка з класом для стилізації -->

Підсумок

HTML — це основа всіх веб-сторінок. Розуміння структури документа, а також правильне використання тегів <html>, <head> і <body> є важливими для створення якісних і коректних веб-сторінок. Ці теги дозволяють розділяти метаінформацію, структуру та контент, що забезпечує правильну роботу сайту як на комп'ютерах, так і на мобільних пристроях.
