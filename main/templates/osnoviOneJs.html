Змінні, типи даних і оператори

У JavaScript змінні використовуються для збереження даних, з якими працює програма. Наприклад, можна зберегти ім’я користувача, число або результат обчислення.

🔹 Як створити змінну

Є три ключові слова для створення змінних:

  • var — старий спосіб (не рекомендується).
  • let — використовується для змінних, які можна змінювати.
  • const — для констант (значення не змінюється).
let name = "Оля";
const age = 20;
var city = "Київ";

📘 Типи даних у JavaScript

Існує кілька основних типів даних:

  • string — рядки (текст) → "Привіт"
  • number — числа → 25
  • boolean — логічні значення → true або false
  • undefined — змінна оголошена, але не має значення
  • null — “порожнє” значення
  • object — складні структури (масиви, об’єкти)
let text = "Привіт!";
let number = 42;
let isOnline = true;
let nothing = null;
let person = {name: "Оля", age: 20};

🧮 Оператори

Оператори дозволяють виконувати дії з даними — наприклад, додавання, порівняння або логічні операції.

Арифметичні оператори:

  • + — додавання
  • - — віднімання
  • * — множення
  • / — ділення
  • % — залишок від ділення
let a = 10;
let b = 3;
let result = a % b; // 1

Оператори порівняння:

  • == — дорівнює
  • === — строго дорівнює (перевіряє ще й тип)
  • != — не дорівнює
  • >, <, >=, <= — більше/менше
