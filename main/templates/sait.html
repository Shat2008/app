Як працюють HTML, CSS і JavaScript разом?

HTML формує каркас сторінки, CSS оформлює, а JavaScript робить її “живою”.

<!DOCTYPE html>
<html>
  <head>
    <style>
      h1 { color: blue; text-align: center; }
    </style>
  </head>
  <body>
    <h1>Привіт, світ!</h1>
    <script>
      alert("JavaScript працює!");
    </script>
  </body>
</html>
