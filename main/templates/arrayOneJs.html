Створення та методи масивів

Масиви — це колекції даних, які зберігають кілька значень в одному об'єкті.

🔹 Створення масиву

let fruits = ["Яблуко", "Банан", "Апельсин"];
let numbers = [1, 2, 3, 4, 5];
let mixed = [1, "Два", true];

🔹 Основні методи масивів

  • push() — додає елемент у кінець
  • pop() — видаляє останній елемент
  • shift() — видаляє перший елемент
  • unshift() — додає елемент на початок
  • length — кількість елементів
  • forEach() — перебір елементів
let fruits = ["Яблуко", "Банан"];
fruits.push("Апельсин"); // ["Яблуко","Банан","Апельсин"]
fruits.pop(); // ["Яблуко","Банан"]
console.log(fruits.length); // 2

fruits.forEach(function(item, index) {
    console.log(index + ": " + item);
});

🎮 Міні-практика

Додаємо елемент у масив та показуємо результат:

💡 Висновок:

  • ✔ Масиви зберігають декілька значень у одній змінній.
  • ✔ Основні методи: push, pop, shift, unshift, length, forEach.
  • ✔ Масиви можна змінювати динамічно за допомогою методів.
