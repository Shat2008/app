Пошук і зміна елементів сторінки

DOM (Document Object Model) дозволяє JavaScript отримувати доступ до елементів сторінки та змінювати їх вміст, стиль або структуру.

🔹 Пошук елементів

Є кілька методів для пошуку елементів:

  • getElementById — знаходить елемент за id
  • getElementsByClassName — повертає колекцію елементів за класом
  • getElementsByTagName — повертає колекцію елементів за тегом
  • querySelector — знаходить перший елемент за CSS-селектором
  • querySelectorAll — знаходить всі елементи за CSS-селектором
let title = document.getElementById("header");
let buttons = document.getElementsByClassName("btn");
let allDivs = document.getElementsByTagName("div");
let firstLink = document.querySelector("a");
let allLinks = document.querySelectorAll("a");

🔹 Зміна елементів

Можна змінювати текст, HTML та стилі:

let para = document.getElementById("text");
para.innerText = "Новий текст"; // змінює текст
para.innerHTML = "<b>Жирний текст</b>"; // змінює HTML
para.style.color = "red"; // змінює стиль
