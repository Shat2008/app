Шрифти, розмір, товщина, вирівнювання тексту

У CSS є багато властивостей для роботи з текстом: шрифти, розмір, товщина та вирівнювання. Розглянемо основні.

1. Шрифти (font-family)

Властивість font-family задає, який шрифт використовувати:


p {
    font-family: Arial, sans-serif;
}
h1 {
    font-family: "Times New Roman", serif;
}

Можна вказувати декілька шрифтів через кому — браузер обере перший доступний.

2. Розмір тексту (font-size)

Розмір тексту задається у пікселях (px), відсотках (%), em, rem тощо:


p {
    font-size: 16px;
}
h1 {
    font-size: 2em; /* в 2 рази більший за базовий */
}

3. Товщина тексту (font-weight)

Властивість font-weight задає товщину шрифту:

  • normal — звичайна
  • bold — жирна
  • 100, 200 ... 900 — конкретні значення товщини

p {
    font-weight: normal;
}
strong {
    font-weight: bold;
}

4. Вирівнювання тексту (text-align)

Властивість text-align задає горизонтальне вирівнювання:

  • left — ліворуч
  • center — по центру
  • right — праворуч
  • justify — вирівнювання по ширині

p {
    text-align: justify;
}
h1 {
    text-align: center;
}

Поради

  • ✅ Використовуй font-family з запасними шрифтами.
  • ✅ Для заголовків можна застосовувати більший font-size і font-weight bold.
  • ✅ text-align: justify; робить текст акуратним для абзаців.
