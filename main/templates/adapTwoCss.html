Приклади адаптивного сайту

1. Макет mobile-first

Створюємо адаптивний макет, де спочатку задаються стилі для мобільних пристроїв, а потім для більших екранів.


body {
    font-family: Arial, sans-serif;
    margin: 0;
    padding: 0;
}

header, nav, .content, .sidebar, footer {
    padding: 10px;
}

/* Мобільні пристрої */
.content {
    width: 100%;
}

/* Планшети */
@media (min-width: 768px) {
    .content {
        width: 70%;
    }
    .sidebar {
        display: block;
        width: 25%;
    }
}

/* Десктопи */
@media (min-width: 1024px) {
    .content {
        width: 65%;
    }
    .sidebar {
        width: 30%;
    }
}

2. Гнучкі зображення та блоки

Використовуємо max-width і відсотки, щоб елементи підлаштовувались під екран.


img {
    max-width: 100%;
    height: auto;
}

.container {
    display: flex;
    flex-wrap: wrap;
}

.box {
    flex: 1 1 100%;
}

@media (min-width: 768px) {
    .box {
        flex: 1 1 45%;
        margin: 10px;
    }
}

3. Адаптивне меню

При малих екранах меню ховається або стає кнопкою “гамбургер”.


@media (max-width: 480px) {
    nav .nav-links {
        display: none;
    }
    nav .nav-logo1 {
        display: inline-block;
    }
}

4. Поради для адаптивного дизайну

  • ✅ Використовуйте відсоткові або відносні одиниці (%, em, rem).
  • ✅ Гнучкі макети з flexbox або grid краще підлаштовуються під різні екрани.
  • ✅ Тестуйте сайт на смартфонах, планшетах та великих моніторах.
