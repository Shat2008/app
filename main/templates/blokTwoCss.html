Flexbox та Grid для макета сторінки

Вступ

Flexbox і Grid — це сучасні інструменти CSS для розташування елементів на сторінці. Flexbox працює в одному напрямку (рядок або колонка), Grid дозволяє будувати двовимірні макети (рядки та колонки одночасно).

1. Flexbox

Flexbox дозволяє розташовувати елементи всередині контейнера легко та гнучко.

Приклад:


<div style="display: flex; gap: 10px;">
    <div style="background-color: lightblue; padding: 20px;">Блок 1</div>
    <div style="background-color: lightgreen; padding: 20px;">Блок 2</div>
    <div style="background-color: lightcoral; padding: 20px;">Блок 3</div>
</div>

Елементи розташовані в рядок з проміжками.

2. Grid

Grid дозволяє будувати сітку з рядків і колонок для складних макетів.

Приклад:


<div style="display: grid; grid-template-columns: 1fr 2fr; gap: 10px;">
    <div style="background-color: lightblue; padding: 20px;">Блок A</div>
    <div style="background-color: lightgreen; padding: 20px;">Блок B</div>
    <div style="background-color: lightcoral; padding: 20px;">Блок C</div>
</div>

Елементи розподіляються по двох колонках з різною шириною.

Порівняння

Модель Підходить для Особливості
Flexbox Одновимірні макети Рядок або колонка, гнучке вирівнювання та проміжки
Grid Двовимірні макети Рядки та колонки одночасно, контроль ширини/висоти

Висновок

Flexbox і Grid — потужні інструменти для макетів. Flexbox підходить для простих рядків або колонок, Grid — для складних сіток.
