Що таке JavaScript і для чого він потрібен?

JavaScript — це мова програмування, яка оживляє веб-сторінки. Якщо HTML відповідає за структуру сайту, а CSS — за його зовнішній вигляд, то саме JavaScript додає інтерактивність: реагує на натискання, змінює вміст, запускає анімації та багато іншого.

Приклади того, що робить JavaScript:

  • ✅ Відображає спливаючі вікна, повідомлення або підказки.
  • ✅ Перевіряє введені дані у формах (наприклад, чи правильно введено email).
  • ✅ Дозволяє створювати слайдери, калькулятори, інтерактивні тести.
  • ✅ Реагує на кліки, рух миші або натискання клавіш.
  • ✅ Оновлює сторінку без її перезавантаження (технологія AJAX).

Чому JavaScript важливий?

Без JavaScript більшість сучасних сайтів виглядали б як звичайні статичні сторінки. Саме він дозволяє створювати веб-додатки — від простих ігор до складних платформ, як Gmail, YouTube або Instagram.

Як підключити JavaScript до HTML?

Є три основні способи:

  1. Вбудований у HTML: у тегу <script> прямо на сторінці: 
    <script>
alert('Привіт, світ!');
</script>
  2. Зовнішній файл: зберігаєш код у окремому файлі script.js і підключаєш: 
    <script src="script.js"></script>
  3. В атрибутах HTML: наприклад: 
    <button onclick="alert('Клік!')">Натисни мене</button>

JavaScript у дії

Нижче приклад коду, який реагує на натискання кнопки:

<button onclick="changeText()">Натисни</button>
<p id="demo">Початковий текст</p>

<script>
function changeText() {
    document.getElementById("demo").innerHTML = "Текст змінено!";
}
</script>

Коли користувач натискає кнопку, JavaScript змінює текст на сторінці — ось так просто!
