## 3. Вимоги до апаратних пристроїв комп’ютера

- Тип процесора: x64-сумісний процесор (рекомендується Intel Core i5 або аналогічний)  
- Об’єм оперативної пам’яті: Мінімум 4 ГБ RAM, рекомендується 8 ГБ або більше  
- Об’єм дискового простору: Близько 500 МБ для встановлення програми та залежностей  
- Наявність додаткових пристроїв: Не потрібно, але рекомендується стабільне інтернет-з'єднання для роботи з API

## 4. Вимоги до системи та системних установок

- Операційна система: Windows 10 або новішої версії  
- Компоненти системи: Наявність Python 3.13, віртуального середовища (venv), додаткових системних бібліотек не потрібно

## 5. Вимоги до програмного забезпечення, яке має бути встановлено на демонстраційному комп’ютеру

- Python 3.13  
- Django (версія вказана в requirements.txt)  
- Залежності з requirements.txt: cohere, django, python-dotenv та інші  
- Веб-браузер для доступу до інтерфейсу

## 6. Відомості про файл запуску

Файл запуску: manage.py  
Команда для запуску: `python manage.py runserver`  
Після запуску сервер доступний за адресою http://127.0.0.1:8000/

## 7. Відомості про особливості установки та роботи програми

Встановлення:  
1. Створіть віртуальне середовище: `python -m venv .venv`  
2. Активуйте середовище: `.\.venv\Scripts\Activate.ps1`  
3. Встановіть залежності: `pip install -r requirements.txt`  
4. Створіть файл .env з API ключем Cohere  
5. Виконайте міграції: `python manage.py migrate`  
6. Запустіть сервер: `python manage.py runserver`  

Особливості роботи: Програма працює у веб-браузері, взаємодіє з Cohere API для генерації відповідей у чаті. Потрібен діючий API ключ. Безпека: Не коммітте .env файл у репозиторій.

## 8. Теоретична частина

### Платформа розробки та архітектура проєкту

Django — це високорівнева веб-платформа, написана на Python, яка дозволяє швидко створювати веб-додатки. Вона слідує архітектурному патерну MTV (Model-Template-View), що забезпечує чіткий розподіл логіки.

Основні компоненти Django:
- **Моделі (Models)**: Представляють дані та бізнес-логіку. Використовують ORM для взаємодії з базою даних.
- **Представлення (Views)**: Обробляють запити користувача та повертають відповіді.
- **Шаблони (Templates)**: Відповідають за відображення даних користувачу.

Django підтримує інтеграцію з різноманітними базами даних, включаючи SQLite, PostgreSQL та інші.

### Розбиття логіки на контролери (Views)

В Django views обробляють HTTP-запити. Існують функційні та клас-базовані views. Views взаємодіють з моделями для отримання даних та передають їх у шаблони.

### Шаблони та статичні файли

Django використовує власну систему шаблонів для генерації HTML. Шаблони можуть включати статичні файли (CSS, JS, зображення).

### ORM Django та бази даних

Django ORM дозволяє працювати з базами даних через Python об'єкти. Підтримує міграції для управління схемою БД.

### JavaScript-складова

JavaScript використовується для інтерактивності на клієнтській стороні. В проекті JS файли забезпечують динамічне оновлення контенту, обробку форм та інтерактивні елементи.
